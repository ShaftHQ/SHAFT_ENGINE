# shaft-ai

**Purpose:** Optional direct AI-provider adapters for SHAFT Pilot.

**Use or skip:** Optional module. Depend on `io.github.shafthq:shaft-ai` only for direct provider adapters. Skip it to keep a consumer build on the core engine.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-ai -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
