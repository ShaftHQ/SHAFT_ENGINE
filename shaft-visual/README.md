# shaft-visual

**Purpose:** Optional OpenCV, Applitools Eyes, and Shutterbug visual processing for SHAFT Engine.

**Use or skip:** Optional visual module. Use it for visual checks. Skip it for non-visual tests.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-visual -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
