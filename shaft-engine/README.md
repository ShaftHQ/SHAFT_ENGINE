**Purpose:** SHAFT is a unified test automation engine with a wizard-like syntax for Web, Mobile, API, CLI, Database, and native tests.

**Use or skip:** Start here for product tests. Depend on `io.github.shafthq:shaft-engine`. Skip this module when the change is only an optional add-on.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-engine -am -DskipTests package
```
