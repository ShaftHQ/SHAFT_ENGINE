# shaft-capture

**Purpose:** Deterministic SHAFT Capture recording, privacy, TestNG generation, and replay validation.

**Use or skip:** Use this module for recording, privacy, generated TestNG, and replay. Skip it when capture is not in the change.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-capture -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
