# shaft-mcp

**Purpose:** Model Context Protocol server for SHAFT browser automation.

**Use or skip:** Use this module for the MCP server. Skip it for library-only test changes that do not call MCP tools.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-mcp -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
