In tests/scripts/test_knowledge_stores.py the fake mempalace.cmd used `echo mempalace %*>>"%KNOWLEDGE_STORES_LOG%"`. When the last argv token is a digit (for example `--results 4`), cmd parses `4>>file` as redirecting fd 4, so stdout never hits the log and `--palace` is missing from tokens. Observed while adding #5084 `--query` tests (PR #5085, 694d1f49ec). Fix: keep a space before `>>` (`echo mempalace %* >>log`).
