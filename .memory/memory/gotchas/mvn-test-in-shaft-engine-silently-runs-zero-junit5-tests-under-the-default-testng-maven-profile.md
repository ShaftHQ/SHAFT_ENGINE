shaft-engine's pom.xml defaults to the `testng` Maven profile (TestNG surefire provider active). Running a plain `mvn test` (or `mvn test -Dtest=<JUnit5Class>`) against a JUnit5 test class reports `Tests run: 0` with no error and no failure -- it reads as a clean pass rather than as nothing having executed. This is the same class of silent-zero failure as #4079/#4074. Existing tests are affected, not just new ones (e.g. JunitExtensionLifecycleTest). Reproducing CI's real run requires `-Pjunit -DskipTestNG=true` plus regenerating the gitignored `src/test/resources/META-INF/services/*` service-loader files (see decision.generated-test-scaffolding-is-ignore-everywhere-shaft-engine-jar-ships-the-service-registrations) before the JUnit5 tests actually execute locally.
