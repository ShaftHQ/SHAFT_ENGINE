Managed-local `shaft-cli setup status` and `setup verify` print tab-separated `target readiness version detail`. Version is empty unless READY. Detail is the snapshot action. They do not list revision, license, provenance, size, floors, update, cleanup, or fallback when disabled or when the cache is missing. The pin table on docs/start/local-infrastructure.mdx is the documented inventory; commands report readiness/version/action. Doctor/MCP `doctor local-ai-status` and `doctor_managed_local_ai_status` remain enablement/DISABLED only. Enablement is local-processing consent, not remote consent or tool approval.
