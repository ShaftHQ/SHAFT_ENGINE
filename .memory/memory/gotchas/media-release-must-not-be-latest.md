Publishing the media release `shaft-hero-video-20261017` with `gh release edit --draft=false --latest=false` still made it the repo's latest release (the `releases/latest` API returned it). Restore it with `gh api -X PATCH repos/ShaftHQ/SHAFT_ENGINE/releases/<id of the version release> -f make_latest=true`, then verify with `gh api .../releases/latest -q .tag_name`. Changing the latest flag does not re-emit `release: published`.
