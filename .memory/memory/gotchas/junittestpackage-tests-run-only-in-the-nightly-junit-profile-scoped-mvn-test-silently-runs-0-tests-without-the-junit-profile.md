shaft-engine junitTestPackage tests run ONLY in the nightly e2eTests.yml Ubuntu_JUnit_E2E job (mvn with the junit profile, skipTestNG=true, test filter Junit*,MoonTests); a plain scoped mvn -pl shaft-engine test with a JUnit class filter runs 0 tests silently (surefire XML tests=0) -- locally you must add -Pjunit -DskipTestNG=true. This is how PR #4344 (failAction AssertionError to RuntimeException, issue #4341) updated BrowserActionsCoverageUnitTest and AndroidTouchActionsCoverageUnitTest but missed JunitCoreAssertionMigrationTest.failActionShouldPreserveMessageAndRootCause, which then broke the nightly (#4359, fixed by updating the stale expectation).
