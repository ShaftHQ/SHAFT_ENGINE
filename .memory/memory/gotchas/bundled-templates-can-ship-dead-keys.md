Every `custom.properties` template had `screenshotParamsWhenToTakeAScreenshot` while SHAFT reads `screenshotParams_whenToTakeAScreenshot`, so the value was silently ignored and users copied the typo (#7085). `UnknownPropertyKeysTest.bundledDefaultPropertyFilesDoNotWarn` now checks the bundled files against the `@Key` allow-list; when adding a template key, use the `@Key` value, not the getter name.
