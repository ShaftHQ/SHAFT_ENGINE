is_transient_github_http_error used \\b(?:HTTP\\s*)?(?:429|503)\\b, so a CheckWatchError wrapping json.JSONDecodeError such as 'Expecting value: line 1 column 430 (char 429)' or 'line 429' was treated as transient and burned the poll budget. Ticket #5055 forbids retrying malformed JSON. Require an HTTP token: \\bHTTP\\s*(?:429|503)\\b. Existing GREEN tests raise 'gh pr checks failed: HTTP {status}'. Do not match bare 429/503.
