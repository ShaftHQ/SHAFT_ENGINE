After Maven BUILD SUCCESS, required PR Gate / CodeQL / dependency-submission jobs can still fail because GitHub returns 429 Too Many Requests or 503 Service Unavailable while downloading actions/setup-java, codecov/codecov-action, or github/codeql-action. That is infrastructure (#5050), not a product-test failure. Do not change product tests. Inspect the failing job log, then wait for the run to complete and gh run rerun --failed.
