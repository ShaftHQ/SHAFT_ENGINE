Gradle Daemon JVM criteria take precedence over JAVA_HOME and org.gradle.java.home. SHAFT therefore does not pin an exact daemon toolchain for `shaft-intellij`. The checked-in Gradle 9.3 wrapper and all plugin CI lanes now run on JDK 25, while `settings.gradle.kts` rejects daemon JDKs newer than 25 because Gradle 9.3 does not support running on JDK 26. Raise this ceiling only together with a wrapper upgrade and repeated verification.
