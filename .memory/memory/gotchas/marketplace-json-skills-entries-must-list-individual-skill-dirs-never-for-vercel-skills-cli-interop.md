The vercel-labs skills CLI (v1.5.20, verified in bundled dist/cli.mjs getPluginSkillPaths) resolves each marketplace.json plugin skills[] entry as dirname(join(pluginBase,entry)) -- the PARENT becomes the scan container. An entry of ./ therefore scans the REPO ROOT (finds nothing under shaft-skills/) and silently discovers 0 skills, while Claude Code accepts both containers and skill dirs. Only shape both tools resolve: list each skill directory explicitly (./shaft-cli, ./shaft-mcp, ...). strict:false in the marketplace entry means no per-plugin plugin.json is needed.
