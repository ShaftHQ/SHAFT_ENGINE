`TraceEventRecorder.startForBackend` must construct its backend-owned event directly. Routing it through `start(..., null)` reaches `backend(null)`, which consults the active SHAFT WebDriver/Playwright session. That hidden lookup violates zero-provider preflight for operations such as invalid-target mobile Evidence capture and can introduce unrelated driver interactions before validation. The regression is bound by `MobileEvidenceActionsTest` invalid-target `verifyNoInteractions` assertions and `MobileEvidenceNamespaceTraceTest` backend-owned event assertions. Commit `9a56130f43` fixed the owner by preserving trace suppression/IDs while avoiding driver/backend resolution.
