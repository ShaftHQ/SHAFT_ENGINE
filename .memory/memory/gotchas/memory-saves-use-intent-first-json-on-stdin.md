This repo's installed Memory CLI writes with `memory save --stdin` or `memory save --stdin --dry-run` using intent-first JSON `{task, nodes, stale, supersede, delete}`. The older `memory remember` entrypoint is gone; do not rely on stale template examples such as `memory save --id`, free-form `memory save` text arguments, or hand-edited `.memory/**` sidecars. Learning Sessions use save as the default write path (#5852).
