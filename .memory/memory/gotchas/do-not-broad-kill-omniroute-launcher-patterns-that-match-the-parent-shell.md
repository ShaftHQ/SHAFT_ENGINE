Using broad process-name kill patterns (for example pkill -f matching the launcher argv) against OmniRoute or implementer command lines killed the dispatching shell itself and aborted productive launches. Start long jobs with nohup plus distinct worktree process ids; never broad-kill on the launcher argv; prefer targeted kill of recorded child process ids only. See chaos-engine/skills/omniroute/references/process-lifecycle.md. Issue #5770.
