SECRET_LIKE labels for authorization, api_key, and bearer must allow optional quotes around the key, the same way FAILED_LOCATOR already allows optional quotes around selector. Compact JSON objects put the quote between the label and the colon, so a label that must sit immediately against : or = leaves the credential value in the captured AiRequest. Evidence: AutobotServiceTest.providerChatRedactsSecretValuesAndRemoteProvidersStillRequireRemoteConsent and McpDoctorRemediationServiceTest.unavailableProviderKeepsAdvisoryProseAndAddsNoExecutableAction.
