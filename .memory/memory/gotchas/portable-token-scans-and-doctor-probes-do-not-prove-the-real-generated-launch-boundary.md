When a harness generates tool or MCP configurations, review the exact command that clients execute, not only doctor/status helpers. A classifier invoked by doctor can still be bypassed by the generated launcher. Review the launcher under its real interpreter flags: dynamic module loading can recreate receipt-absent __pycache__ files when tests use -B. Parse the complete forwarded argument contract, including --option=value and duplicate forms; checking only separate named tokens can validate one value while the downstream parser applies another. Likewise, a forbidden-token scan can miss semantic identity assembled from adjacent string literals; reconstruct constant expressions and inspect resulting arguments and receipts. Evidence: integration review of chaos-engine/tool.py and generated MemPalace MCP configurations exposed the missing real-launch classifier, import-time bytecode creation, and unchecked attached-option overrides; review of portable INSTALL/README exposed a split-literal repository identity despite a clean raw-token scan.
