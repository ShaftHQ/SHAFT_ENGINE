IntelliJ's shared run-configuration scheme loader reads only the first `<configuration>` child from a shared `<component>` XML file. Generated SHAFT projects must therefore store each default Application, JUnit, TestNG, and Cucumber Java template in its own XML file under `.idea/runConfigurations`; every template must set `shortenClasspath` to `ARGS_FILE`. Combining multiple default configurations in one shared XML silently leaves gutter-created test configurations without the command-line shortener.
