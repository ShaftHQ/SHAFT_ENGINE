`shaft-intellij` uses the checked-in Gradle 9.3 wrapper with JDK 25 as the build runtime. Its source/target/release remain Java 17 for IntelliJ compatibility. The build rejects daemon JDKs newer than 25 until the wrapper is upgraded and verified. Use `shaft-intellij/gradlew[.bat] -p shaft-intellij ...`; do not install JDK 21 or a separate system Gradle solely for this module. Issue #3784 recorded one Windows OpenJDK 25.0.1 G1 crash even with Gradle 9.3, but #4779 superseded the workaround after two fresh full Windows no-daemon JDK 25 runs passed. For UI screenshots, run `ShaftPluginScreenshotRendererTest` with an explicit screenshot directory and inspect the rendered output.
