When charging shaft.trace.maxSessionMb, call TraceSessionBudget.tryReserve before copying an attempt-indexed ZIP or writing screenshots/*.png. Setting archiveName or writing files first, then ignoring a failed reserve, leaves ghost attempt paths and unpublished bytes on disk (review F1/F2 on PR #5139 / #4826). The sidecar regression is FailureTraceReporterTest.sessionBudgetShouldSkipScreenshotSidecarsInsteadOfWritingThemAnyway.
