On Windows, a directory junction can redirect candidate staging even though pathlib.Path.is_symlink() is false. Trust-boundary staging must inspect os.lstat(path).st_file_attributes for stat.FILE_ATTRIBUTE_REPARSE_POINT in addition to resolving containment and rejecting symlinks. Check symlink and resolved-outside-root diagnostics before the generic reparse-point rejection so existing failure messages remain stable. This was proven by real outside-root and in-root junction regressions during agnix promotion #4702.
