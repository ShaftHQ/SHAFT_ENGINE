PR Gate Release-note governance fails ready human PRs when none of `breaking-change`, `bug`, `enhancement`, or `skip-release-notes` is applied. Apply exactly one classification label in the same `gh pr create` step (bug for fixes, enhancement for features). Not limited to Wave or strategy-matrix PRs. Issue #5768. Applying two classification labels (for example both `bug` and `enhancement`) also fails; keep exactly one.
