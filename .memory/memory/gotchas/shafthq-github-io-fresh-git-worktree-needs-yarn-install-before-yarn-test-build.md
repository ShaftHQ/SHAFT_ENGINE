node_modules is gitignored (shafthq.github.io/.gitignore:2 `/node_modules`) and is never shared across git worktrees -- each worktree is a separate working directory with its own untracked files. A fresh worktree of shafthq.github.io fails `yarn test`/`yarn build` with `ERR_MODULE_NOT_FOUND '@google/genai'` (a real dependency, package.json:43) until `yarn install` runs in that worktree first. The error reads exactly like a real dependency regression and cost a false lead before the missing-install was identified (#4048, docs PR #895). How to apply: `yarn install` is step one in any freshly created shafthq.github.io worktree, before any yarn script.
