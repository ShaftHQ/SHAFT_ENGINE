Do not use an unscoped local `mvn test` as a pure unit gate for the SHAFT reactor. The reactor includes Appium fixtures whose default `MobileTest` path configures BrowserStack, so a local full-test invocation can begin an external remote session rather than finish as an offline unit suite. Use the affected module/unit selectors for local proof and run BrowserStack or compatible-provider acceptance only through their explicit authorized suites; use full-reactor `package -DskipTests=true` for compile/package/source/Javadoc coverage.
