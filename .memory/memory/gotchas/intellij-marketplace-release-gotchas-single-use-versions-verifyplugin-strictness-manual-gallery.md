Marketplace plugin versions are single-use, so a rejected or partially uploaded version must be followed by a new date-based pluginVersion. Optional plugin descriptor XML must not contain illegal `--` comment content. `verifyPlugin` strict failure levels and `-Xlint:deprecation -Werror` are configured in `shaft-intellij/build.gradle.kts`. Marketplace gallery images remain a manual upload; renderer shots go to `marketplace-media/`. Run local verification with JDK 25 and the checked-in wrapper: `shaft-intellij/gradlew[.bat] -p shaft-intellij verifyPlugin`; reports land in `shaft-intellij/build/reports/pluginVerifier/`.
