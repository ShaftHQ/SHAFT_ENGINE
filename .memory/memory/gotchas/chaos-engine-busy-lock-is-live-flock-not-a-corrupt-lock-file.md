`CE-INSTALL-FAILED: another ChaosEngine operation is already running` means exclusive `fcntl.flock` on `.chaos-engine.lock` could not be acquired. The lock *file* is expected to exist (magic `chaos-engine-lock-v1`); do not delete it. Wait for the holder PID shown by install/doctor diagnostics, and do not overlap curl|bash one-liners with install/doctor/repair. Upgrading a `repository` distribution install must pass `--distribution repository`. Issue #5879; PR #5880.
