PR #4095 armed auto-merge and merged once the required PR-gate checks passed, but those checks never ran the Grid job the PR was actually fixing; the Grid job then failed post-merge and issue #4037 had to be reopened. Rule: before arming auto-merge, confirm the job that actually proves the fix (the one exercising the changed behavior) is itself part of the required check set gating the merge -- a green 'PR Gate Summary' is not sufficient when the acceptance criterion lives in a workflow/job pr-gate.yml does not run (e.g. schedule/dispatch-only Grid or E2E jobs). If it isn't in the gate, verify that job manually before (or instead of) arming auto-merge.
