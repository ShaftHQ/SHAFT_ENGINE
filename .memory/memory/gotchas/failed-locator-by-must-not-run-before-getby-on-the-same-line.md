The origin/main FAILED_LOCATOR By.* alternative uses [^\r\n,;]+. Selenium By.cssSelector().toString() is 'By.cssSelector: #id' with no closing paren, so that class consumes later text on the same line until a comma. Playwright getByRole("button", { name: "canary" }) therefore loses getByRole("button" and leaves the name token after the comma. One union regex does not fix this. Apply Playwright getBy*, SHAFT.GUI.Locator.<method>(...), and Selenium 3 {using,value} replacements before the legacy By/locator/selector pattern.
