Gemini 3.x models (e.g. gemini-3.5-flash) use generationConfig.thinkingConfig.thinkingLevel (minimal/low/medium/high) to bound reasoning depth; Gemini 2.5-series models use the older numeric thinkingConfig.thinkingBudget instead. Thinking tokens are drawn from the same maxOutputTokens allowance as the answer on both families. Sending thinkingLevel to a 2.5-series model is not documented as supported, so GeminiProvider.buildPayload gates it on model().startsWith("gemini-3") (GeminiProvider.java) rather than applying unconditionally. Source: Gemini API docs via context7 (/websites/ai_google_dev_gemini-api), confirms gemini-3.5-flash's output ceiling is 65,000 tokens.
