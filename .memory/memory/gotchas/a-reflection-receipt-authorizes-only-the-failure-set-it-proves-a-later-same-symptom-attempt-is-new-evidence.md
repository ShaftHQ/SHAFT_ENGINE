After a valid reflection receipt, do not assume the same previously blocked mutation may be retried automatically. The reducer binds the receipt to the exact active fingerprint set at that checkpoint. A later attempt that fails with the same symptom is intentionally newer evidence and reopens deep reflection. Before retrying, change the diagnostic or approach; if the mutation is optional cleanup, preserve and disclose the artifact instead of cycling. This behavior is correct even when the earlier receipt proved a different recovery action in the same task.
