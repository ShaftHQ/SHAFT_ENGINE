XML forbids the literal sequence -- inside a comment body (<!-- ... --> must not contain -- except as the closing delimiter). If a pom.xml comment happens to contain a literal double-hyphen (e.g. in prose, a code snippet, or a diff excerpt pasted into a comment), Maven fails with a 'Non-parseable POM' error whose reported line/location does not point at the actual offending comment -- it points somewhere else in the file, which sends debugging in the wrong direction. When a POM fails to parse with a location that looks unrelated to any real change, search the diff for '--' inside XML comments before trusting the reported line number.
