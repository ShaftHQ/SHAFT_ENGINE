Before running SHAFT's compatible local Appium recording acceptance, verify that the selected Android SDK has build-tools installed and that `aapt2` is available. Appium 3.6.0 / UiAutomator2 7.6.2 session setup failed before the test when the Android 36 SDK lacked `aapt2`; installing Android build-tools 36.0.0 made the unchanged exact recording acceptance pass 1/0/0/0. Treat this as provider-environment preflight, not a product failure or reason to skip the test.
