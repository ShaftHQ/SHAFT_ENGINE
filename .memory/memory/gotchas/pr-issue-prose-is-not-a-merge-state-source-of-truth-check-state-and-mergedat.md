Twice in one session an agent was told a PR had 'landed' while the PR was still open. Prose in a PR body, issue comment, or chat message describing work as done/merged/landed is a claim, not a fact. The actual check is `gh pr view <n> --json state,mergedAt` (verified: on an open PR this returns `state: "OPEN"`, `mergedAt: null`); trust that over any narrative description of the PR's status.
