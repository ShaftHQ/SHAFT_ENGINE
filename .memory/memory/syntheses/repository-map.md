Maven multi-module reactor rooted at pom.xml (io.github.shafthq:shaft-parent). Reactor modules: shaft-engine (core framework: GUI/API/DB/CLI drivers, validations, properties, listeners), shaft-pilot-core (AI pilot), shaft-capture and shaft-capture-proxy (recorder + proxy), shaft-doctor, shaft-ai, shaft-heal (self-healing locators), shaft-mcp (MCP server, Spring Boot), shaft-cli, shaft-browserstack, shaft-video, shaft-visual, shaft-sikulix, report-aggregate, shaft-bom, legacy-shaft-engine. Outside the reactor: shaft-intellij is a standalone Gradle Kotlin-DSL build for the IntelliJ plugin; shaft-skills holds agent-facing skill guidance; shaft-upgrader is a separate module directory. Tooling and automation: scripts/ (agents, ci, maintenance, mcp - Python), tools/ (repository-map graphify generator, agent-infra, intellij-plugin-recording, modularization), tests/ (fixtures, scripts). CI workflows live in .github/workflows/ (pr-gate.yml, e2eTests.yml, e2eLocalTests.yml, mavenCentral_cd.yml, deploy-shaft-mcp.yml, and others). Agent harness: AGENTS.md (canonical), CLAUDE.md adapter, .claude/ (skills, agents, hooks, user-harness), .agents/ (routing bridges), .memory/ (durable memory store). User docs live in the separate shafthq.github.io repository.
