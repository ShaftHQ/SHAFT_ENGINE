The SHAFT docs repo is a SEPARATE repo with default branch `master`. Repository policy permits merge commits only (`allow_merge_commit=true`; squash and rebase disabled), enables auto-merge, and automatically deletes merged head branches. After the independent review gate, arm a docs PR with `gh pr merge <n> --repo ShaftHQ/shafthq.github.io --auto --merge`; do not use squash, rebase, `--admin`, or a manual delete-branch flag. Watch required checks with `py -3 scripts/ci/watch_pr_checks.py --pr <n> --repo ShaftHQ/shafthq.github.io`, inspect check annotations plus PR review comments/conversations, and address every valid finding. The watcher reports green/red only, so also query `gh pr view <n> --repo ShaftHQ/shafthq.github.io --json mergeStateStatus,mergedAt`; fix `DIRTY` conflicts, merge `origin/master` for a `BEHIND` stale head without rewriting visible history, and confirm `mergedAt` is non-null before calling the PR delivered. Deploy/CI policy: the strict required PR gate is `Docs Build`. Current status rollups may also show CodeQL or Cloudflare checks, but those are live-state observations rather than guaranteed gates; Netlify is not guaranteed. Run docs validation locally (`npm run test:docs`, `npm run test:homepage`, `npm run typecheck`). Build fragility: bare `<url>`/`<path>`-style placeholder tokens in `.md` prose fail the Docusaurus MDX build (unclosed-JSX-tag error), silently red-ing the deploy preview until escaped (`\<url\>`); always run `npx docusaurus build` locally and check the REAL exit code (`cmd | tail` masks it) before merging. Assertion note: SHAFT assertions execute immediately on their terminal call; `.perform()` is a redundant no-op. `matchesScreenshot()` used to be the exception (fixed in SHAFT_ENGINE#3524 to take a `VisualComparisonOptions` arg and run immediately).
