AssistantGeminiLiveE2ETest command shape: `gradle test --tests ...AssistantGeminiLiveE2ETest -Dshaft.intellij.liveGemini=true -Dshaft.intellij.liveMcpCommand="<java> @<shaft-mcp.args>" -Dshaft.intellij.workspaceRoot=<dir> -Dshaft.intellij.liveGeminiModel=gemini-2.5-flash` with GEMINI_API_KEY in env (never written to files). The installed shaft-mcp args file pins -Dshaft.mcp.workspaceRoot to %LOCALAPPDATA%/ShaftHQ/shaft-mcp/work, and the system property beats the SHAFT_MCP_WORKSPACE_ROOT env var -- pass that work dir as workspaceRoot (or scope the args file like ShaftMcpProjectScope does) or the MCP rejects 'Autobot working directory is outside the MCP workspace'. Every shaft.intellij.* test property must be explicitly forwarded in shaft-intellij/build.gradle.kts's test { systemProperty(...) } -- unforwarded -D flags silently fall back to defaults inside the test JVM. Google load-sheds gemini-3.5-flash structured-output (responseSchema) calls with 503 'high demand' while trivial payloads/model-list calls return 200; use gemini-2.5-flash for deterministic-ish live runs and expect occasional retries anyway. INVALID_RESPONSE with fallbackReason 'Provider returned malformed JSON.' is NOT only a too-small maxOutputTokens budget (raised to 8k in PR #3371, AutobotService.runProviderChat) -- issue #4072 root-caused it to GeminiProvider.parseStructuredPayload (shaft-ai) reading candidates[0].content.parts[0].text unconditionally; thinking-enabled models (gemini-2.5/3.5-flash) can emit a leading {"thought": true, ...} part before the real answer part, or exhaust the output budget on thinking before ever emitting an answer part, and the old code misread the former as malformed JSON and gave no signal for the latter. Fixed by skipping thought parts and surfacing the candidate's finishReason (e.g. MAX_TOKENS) when no usable answer part remains -- the budget theory alone could not explain the intermittency, since a leading thought part fails regardless of budget size. Headless Swing screenshot rendering paints placeholder glyphs unless IconLoader.activate() runs first (see ShaftPluginScreenshotRendererTest's static block).
