shaft-engine gained HealingFingerprintSeed (plain-data, no shaft-heal dependency) and HealingFingerprintObservation (pageUrl string + By + action + seed), plus HealingProvider.observeFingerprint(...) default no-op and HealingManager.observeFingerprint(...) static dispatcher (no HealingStrategy gate, matching recordOutcome()'s unconditional-dispatch pattern, not observe()'s gated one -- this is an explicit, already-decided call, not a generic per-action hook). Deliberately a NEW method name, not an observe(HealingObservation) overload: overloading would make every existing verify(provider).observe(any()) Mockito call site (e.g. HealingActionsIntegrationTest.java:76) ambiguous to javac, since neither HealingObservation nor HealingFingerprintObservation is a subtype of the other. ShaftHealingProvider.observeFingerprint() (shaft-heal) converts the seed into a real LocatorFingerprint (full 21-arg canonical constructor, domPathChecksum/bounds/nativeAttributes left blank, platform=WEB) and persists via the existing package-private HealingHistoryStore.save(pageKey, originalLocator, context, contextMetadata, fingerprint, empty-string) overload -- no new store, no parallel scorer.
