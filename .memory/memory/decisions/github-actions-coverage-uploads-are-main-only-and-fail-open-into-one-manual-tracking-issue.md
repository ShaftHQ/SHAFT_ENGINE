All GitHub Actions JVM-test jobs must generate or discover their JaCoCo XML reports and invoke the shared coverage uploader after the last test on the failure path. The uploader submits reports to Codecov only when GITHUB_REF is refs/heads/main. JaCoCo generation, report resolution, and Codecov upload failures must not fail the test job; they emit per-job failure evidence. A workflow_run notifier consolidates that evidence into the one open issue labeled code-coverage-failure, deduplicates by workflow run, and never auto-closes the issue so closure remains manual.
