The IntelliJ Assistant uses /help as the canonical local capability inventory, with /commands, /mcp-help, and /shaft-help aliases plus natural capability questions. Assistant commands and shaft-cli commands come from their registered surfaces; bundled MCP metadata is the deterministic fallback. A structurally valid live tools/list response is authoritative, including tools: [], while malformed or unavailable discovery is labeled and falls back. Cancelling the help view must not cancel the shared MCP request or unrelated tool calls.
