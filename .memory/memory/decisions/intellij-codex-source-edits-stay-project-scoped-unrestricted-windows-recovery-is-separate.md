The IntelliJ Assistant maps Agent mode with Allow source edits to `codex --ask-for-approval never exec ... --sandbox workspace-write`. It must not silently map that project-scoped checkbox to Codex's no-sandbox flag. When the Codex Windows sandbox cannot launch (for example `CreateProcessWithLogonW failed`), the separate default-off `Run Codex without sandbox` control may select `--dangerously-bypass-approvals-and-sandbox`; its label and tooltip must disclose access outside the open project. Live tests require independent `shaft.intellij.liveAgentE2E` and `shaft.intellij.liveUnrestrictedAgentE2E` gates. Read-only/Ask/Plan runs retain `--sandbox read-only`.
