The superseded-policy scan in tests/scripts/test_agent_harness_portability.py failed three consecutive adversarial reviews, and every defect sat in the same place: a regex asked to make a semantic judgement about English prose. Round 1 (#4461) shipped patterns the test could not actually pin. Round 2 (#4468) found the sentence splitter cutting valid supersession records in half at 'Sec. 3b'. Round 3 (#4469, #4477) found 12 unenforced sub-rules plus a false-positive class that rejected the exact record the Learning-loop table tells an agent to write.

Classify the sub-problems and the pattern is structural, not about authors. 'Does this text contain a known phrase' is mechanical and never failed a round. 'Is this period a sentence end' needs an unbounded abbreviation lexicon. 'Does this sentence record a supersession or assert a policy' and 'is this a cadence policy or an incident narrative' are semantic. Every finding sat in a semantic row.

#4477 proved widening cannot rescue it: 'read', 'cost', 'put', 'set' and 'hit' are their own past tense, and 'review', 'wake' and 'ping' are nouns as readily as verbs, so no lexical rule separates "I read the delegate's output 20 minutes in" from "Read a subagent's output every 20 minutes".

Decision (PR #4513): delete the grammar. SUPERSESSION_RECORD, SENTENCE_BREAK, NON_TERMINAL_ABBREVIATION and INTERVAL_DIRECTIVE are gone. What remains is a phrase list, a noun list plus a figure, and POLICY_RECORD_ALLOWLIST -- memory object ids permitted to name a retired policy, keyed by policy so clearing an object for one is not a blanket pardon for another. Ids are the right key because .memory/events.jsonl records memory.created against them, so a rename orphans history and the id is immutable.

#4461 had rejected an opt-out because it 'needs nothing of the author'. Three rounds falsified that: the automatic inference cost a review round each time. One explicit reviewable line beats an unbounded grammar, and unlike a grammar hole it is visible in review.

Two corollaries worth keeping. First, markup is not prose: WIKI_LINK was listed for deletion, deleted, and put back, because [[...]] is judged by its delimiters and never by what it says. Deleting it turned the house style for citing a memory object into a build failure -- 14 active objects cite by [[id]], and two live ids name a retired policy in their own slug. Second, a positive fixture cannot prove a boundary. DELEGATE_SUBJECT had ten positive fixtures and zero negative ones, so both word boundaries and every stem loosened to \w* survived mutation; the only mutations that died, died against a live-data assertion the module's own docstring calls vacuous. That is guarding a rule by what the data happens to contain, not by a rule.

Proof standard used: every pattern member, boundary, quantifier and code path gets its own mutation. 71 mutations applied one at a time, 71 killed. A first revision claimed 57/57 and the fourth review demonstrated ten survivors it had not tried.
