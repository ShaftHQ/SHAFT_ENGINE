Setup and Settings expose one complete Assistant agent route instead of independently selectable family, runtime, client, and MCP target controls. The selected route appears before Copy setup command and deterministically owns provider, family, runtime, client, and installer target. Changing it invalidates stale MCP and agent readiness; an unchanged route preserves verified state. All command-transfer buttons visibly say Copy because the Marketplace plugin copies or pretypes commands and never executes installer scripts. External desktop or IDE runtimes remain unverified when no observable probe exists.
