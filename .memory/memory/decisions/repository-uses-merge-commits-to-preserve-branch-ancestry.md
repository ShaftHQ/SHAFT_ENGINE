SHAFT_ENGINE accepts merge commits only; squash and rebase merging are disabled. Merge commits keep each delivered topic branch identifiable by commit ancestry, which makes branch cleanup deterministic and removes the recurring need for patch-ID or file-content workarounds after squash merges. GitHub documents that ordinary pull requests merge with --no-ff, while squash and rebase use fast-forward/recreated commits: https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/incorporating-changes-from-a-pull-request/merging-a-pull-request . Repository settings and rulesets were migrated in issue #4665 and PR #4669; merge commit 1ceaa2aa5d755775f5bfe614ef72c02bda3e70e3 is the durable implementation evidence. Keep automatic head-branch deletion enabled and never substitute squash/rebase for this repository.
