PDF document OCR is PDF-only and extends PdfFileManager. Prefer positioned native text; use whole-page Tesseract OCR for scanned or mixed pages. Return immutable document and batch results. Exports are explicit and atomic for searchable PDF, hOCR, TSV, and JSON; searchable export of signed input requires opt-in signature invalidation and encrypted input is rejected. Table extraction remains geometry-based; Tabula and ML table runtimes are excluded. Raster concurrency is bounded, while a caller timeout cannot forcibly terminate an in-progress native Tesseract call.
