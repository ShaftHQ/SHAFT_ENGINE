`scripts/agents/guard.py` strips multi-line quoted strings, Bash heredocs, and PowerShell here-strings as data, then requires Maven or Allure to be the executable at the head of a command segment. A PR body describing a Maven command does not trip R1; real invocations after command separators still block. The same PreToolUse deny implementation serves Claude, Codex, and Grok through an upward-resolving relative hook command. Verify with `python3 scripts/agents/guard.py --self-test`.
