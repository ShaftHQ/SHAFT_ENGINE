# shaft-video

**Purpose:** Optional desktop video recording and FFmpeg integration for SHAFT Engine.

**Use or skip:** Optional module. Use it when desktop video evidence is required. Skip it otherwise.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-video -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
