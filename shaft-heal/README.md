# shaft-heal

**Purpose:** Optional deterministic and explainable element recovery for SHAFT Engine.

**Use or skip:** Optional module. Use it for element recovery. Skip it when locators and healing are outside the task.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-heal -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
