# shaft-browserstack

**Purpose:** Optional BrowserStack SDK integration for SHAFT Engine.

**Use or skip:** Optional cloud module. Depend on it for BrowserStack runs. Skip it for local-only execution.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-browserstack -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
