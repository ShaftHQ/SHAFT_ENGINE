# shaft-intellij

**Purpose:** IntelliJ IDEA plugin for SHAFT. It is a Gradle project, not a Maven reactor module.

**Use or skip:** Use this directory when the task changes the IDE plugin. Skip it for Maven library changes.

## Humans

From the repository root:

```bash
./shaft-intellij/gradlew -p shaft-intellij check
```

Plugin build definition: [build.gradle.kts](build.gradle.kts). Product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
