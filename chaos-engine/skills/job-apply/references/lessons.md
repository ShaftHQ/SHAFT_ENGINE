# Lessons

- Short links may land on a feed post, not a job page; classify before planning the apply route.
- First drafts often lack research-backed structure; run the top-10 research up front.
- Rewrites invent feature wording when they attribute CV skills to a project; verify against the project README before claiming features.
- Ask all required user inputs in one card, up front.
- Agents must not send; a draft the human can edit and send keeps trust.
