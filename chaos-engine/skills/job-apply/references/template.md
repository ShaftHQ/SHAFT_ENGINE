# Abstract email template

Placeholders only. Fill from the posting and the user's answers; never hard-code
identity into the skill.

```
Subject: Application: <Role> (<Location>) - <Applicant name>

Dear <Recruiter first name>,

I'm applying for the <Role> role with <Company> that you posted on <Source>.
<One-line value hook tied to the role>.

What I would bring:
- <Need 1>: <verified quantified achievement>
- <Need 2>: <verified achievement>
- <Need 3>: <verified achievement>
- <Communication or soft need>: <evidence>. Toolkit also covers <post keywords the applicant truly has>.

<Required fields the post asked for, one per line:
 Preferred location / Notice period / Expected salary>

My CV is attached. Would you be open to a 15-minute call this week?
Thank you for your time and consideration.

Best regards,
<Applicant name>
<phone | email>
<profile links>
```
