# Gate checklist (before handing over)

- [ ] Fit triaged; STRETCH/NO-GO flags reported to the user before drafting.
- [ ] Abroad / non-home-country role: base country + remote intent stated near the top.
- [ ] JD gaps listed to the user; none claimed in the draft.
- [ ] All 10 research criteria met (map each to a line in the draft).
- [ ] Every fact has a live or CV source; no vague numbers; unsupported wording removed.
- [ ] User priority order followed; omitted titles absent; CV conflicts flagged.
- [ ] Payroll vendor vs end client worded correctly ("with", not "at", when the vendor only runs payroll).
- [ ] User exclusions honoured in the body.
- [ ] Forms (if used): all required filled; screenshot shown; explicit yes; one submit; confirmation + ID captured.
- [ ] Exactly one email draft exists when the route is email; never sent by the agent.
- [ ] Application ledger updated.
- [ ] Applicant profile reads/writes stayed in the private per-user store (nothing personal added to this skill tree).
- [ ] Abstraction check on the skill tree still passes ([check_abstraction.sh](../scripts/check_abstraction.sh)).
