# Lessons

- Guest jobs API with `f_WT=2` is a seed only; remote usually means in-country.
- Listing card vs job page can disagree on Hybrid vs Remote; job page wins.
- Recruiter-post permalinks come from Activity → Posts → Copy link to post.
- Mouse-wheel loops hang LinkedIn feeds; use End / Page Down in batches.
- Share-profile apply dialogs are write steps needing explicit user approval.
- Region-locked recruiter posts: quote Fit Flags; check tracker before adding.
- Tracker: Found at discovery; Applied only after verified send/submit; read back.
- Reflection → ChaosEngine PR must attach the full detailed lessons markdown
  (safe-to-share), not a compressed summary.
