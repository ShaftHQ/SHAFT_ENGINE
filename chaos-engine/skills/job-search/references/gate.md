# Gate checklist (before handing search results over)

- [ ] Both channels considered (guest API seed + recruiter posts), or Channel B
      explicitly skipped with a reason.
- [ ] Eligibility lines captured verbatim in Fit Flags; no silent drops.
- [ ] Work mode verified on the job (or employer) page; disagreements marked
      `unverified`; no remote claim without confirmation.
- [ ] Tracker rows use stable IDs + permalinks; status Found until real apply;
      read-back after writes; duplicate agency/contact/client checked.
- [ ] Browser used End / Page Down (no wheel-scroll loops).
- [ ] No share-profile dialog confirmed without explicit user approval.
- [ ] Nothing personal written into this skill tree; private per-user store only.
- [ ] Abstraction check passes ([check_abstraction.sh](../scripts/check_abstraction.sh) → [check_abstraction.py](../scripts/check_abstraction.py)).
