# Reflection → ChaosEngine PR attachment rule

After any reflection / retrospective session that motivates a ChaosEngine
improvement PR, the agent **must attach the full, detailed markdown lessons
file** (all safe-to-share details) to that PR — committed under the skill or
referenced from the PR body. A compressed "caveman" summary is not enough;
reviewers need the full reasoning, evidence, and the concrete rule changes.

Strip personal data, credentials, client names, and prices before attaching.
