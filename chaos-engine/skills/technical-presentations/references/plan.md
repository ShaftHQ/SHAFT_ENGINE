# Plan the deck

## 1 Audience and outcome

- Name the audience level: beginners need strict coherence and small segments;
  experts tolerate denser slides (expertise reversal).
- One outcome per section, phrased "By the end you can …". A slide that does
  not serve an outcome goes to the hidden appendix.

## 2 Story arc

- ABT per section: *And* (context) → *But* (problem, myth, failure) →
  *Therefore* (the practice). Works for a slide, a section, or the talk.
- Talk level: Duarte's sparkline, alternating *what is* and *what could be*,
  ending with a call to action.
- Arc per chapter: hook question → what is → but → therefore → checkpoint →
  recap.

## 3 Storyboard

- Sketch or contact-sheet the deck before building. Pick a layout per slide,
  then write the copy to fit it.
- Segment into 7-10 slide blocks; each block ends with a checkpoint (card 10).
- Recurring roadmap or progress tracker on section dividers, current step
  highlighted.
