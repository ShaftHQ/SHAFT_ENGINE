# Harness files

On-demand index of harness files outside every task route, so both entries
(bot `tool.py entry`, CLI `AGENTS.md`) reach the whole harness. Kept complete
by the reachability gate (`scripts/ci/harness_reachability.py`); do not load
unless a file below is the subject of the task.
