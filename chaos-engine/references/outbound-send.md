# Outbound send

License: MIT.

One send rule for every irreversible external send. Job skills point here.
This file is not a skill and it is not always loaded.

## Rule

Default is draft only. A recorded owner standing send permission that names the channel class may send only after the shared gate passes on the exact final text.

The permission lives in the private store. It names a channel class and a date.
A later owner message revokes or narrows it. Owner-in-chat for one send is
approval for that send after the gate, not a standing permission. A standing
order about which drafts to produce is not a send permission.

Writes the permission did not name stay ask-first: form submit, share-profile,
publish, delete, purchase.

## Gate

Follow in order. These are pointers, not copied procedures.

1. Authority. No in-scope standing send permission means draft only. Stop there.
2. Think first. [bot-entry.md](bot-entry.md) section 2a and [bigger-picture-first.md](bigger-picture-first.md).
3. Fit, or whether this should go out at all. Wait on flagged cases.
4. Official recipient and official route only.
5. Fact-gate every claim. Never invent. No secrets, client names, prices, or other people's personal data.
6. Two independent reviewers, neither the writer, each record PASS on the exact final text. A changed text needs a new PASS. Both run `tool.py pre-done` before sign-off ([multi-agent-pdca.md](multi-agent-pdca.md)).
7. A review sign-off is not a send license.
8. Send only when step 1 allows. Then read back the Sent folder or confirmation, write the tracker or log row, and report the proof. Search Sent before any resend. One submit.
9. Named-exception writes stay ask-first unless the permission named them.

No personal data, permission transcript, or applicant fact belongs in this file.
