# Orchestrator bootstrap

Use only after the canonical router selects delegation.

1. Resolve the repositories and live artifacts in scope.
2. Split only independent, bounded assignments.
3. Give each delegate outcome, scope, exclusions, authority, and proof.
4. Keep architecture, conflict resolution, synthesis, and delivery on the main thread.
5. Inspect returned evidence before adopting it.
6. Close delegates when their work ends.

A sequential task skips this reference. Knowledge stores, issues, worktrees, tests, and review are
included only when they materially serve the assignment.
