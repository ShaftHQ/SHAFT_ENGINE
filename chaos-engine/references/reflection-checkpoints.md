# Reflection and learning

Reflection compounds useful behavior; it never gates tools, mutation, delivery, or completion.
Trigger it only after repeated failures with one fingerprint, or at the actual end of a long session.
Elapsed time, missing fields, unavailable stores or services, and absent issue URLs are not triggers.

## Bounded loop

1. Preserve and deliver completed work before reflecting.
2. Name the failed assumption or repeated fingerprint, alternatives considered, changed approach,
   successful proof, and remaining risk.
3. Extract only a reusable rule that would change a future decision. Session metrics, authorization,
   prompts, transcripts, secrets, raw logs, source excerpts, and machine-specific paths are not rules.
4. Search the structural owner first. Update existing code, guidance, test, memory, or tracker instead
   of creating a duplicate policy layer.
5. Keep one destination and one source of truth. If no reusable lesson exists, record nothing.

Use `scripts/agents/reflection.py` only when a bounded local receipt adds value. Its absence, failure,
or incomplete fields are advisory. Continue and complete regardless.
