# English showcase film slate

This is the ordered English slate for the product surfaces a new user meets after the accepted ChaosEngine install film. It does not shoot the films. No media file is produced here.

The accepted English install film stays frozen, including residual rough splice patches in the audio and one closer card that was not asked for. Do not regenerate it, re-encode it, overwrite it, or cut the accepted closer out of it. Regenerating an accepted master to remove bugs the owner already accepted is a failure of this slate.

When someone asks for the next English film, start at film 1 and do not reopen the install master. Produce the six films in the order below, one at a time, and only after the owner names the next number to shoot. This slate does not authorize a recording by itself.

## Shared acceptance

Every later film must meet this list. A film is rejected when it lacks the synthesized-voice line, shows a face, speaks a personal name or a company name, reads a command aloud, or adds a card for a phrase the owner did not ask for.

- Narrate in English with a synthesized voice. Keep a visible synthesized-voice disclosure on every frame.
- Do not show a face, a talking-head avatar, or a likeness. Do not speak a personal name or a company name.
- Show commands, URLs, and file names as text. The voice names the action. It does not say "dot", a script name, a flag, or a URL, and it does not spell the command.
- Time captions to the words inside each spoken phrase. Hold the finished caption through a real pause. Do not spread words evenly across a silence.
- Cuts land on real pauses. Do not time-stretch a take to hide a splice. Rough splice patches are a defect to avoid.
- Record product behavior from the real tree, headless, with Allure set not to open itself (`-Dallure.automaticallyOpen=false`). Show a failure or a skip when the product did not do the thing. Do not claim a report the run did not write.
- A healthy picture is wording from the installer's success report. It is not a claim about one machine's live doctor when that doctor was not healthy.
- No file path from the recording machine, no home directory, and no invented commit id on screen.
- Paid device clouds are not shown as a live session.
- Keep each finished film private until a separate publish approval. This slate does not publish.
- Leave voice-cloning product work on issue 7881. Do not vendor a cloning stack, add a cloning skill, or call a cloud voice API from these films.

## Film 1. The first SHAFT web test

Show the README quickstart. Open a generated project, write the fluent web example that navigates to the SHAFT guide and asserts the main heading, run `mvn test` headless, and show that the run produced steps, a screenshot, and logs. The voice names the action. The picture shows the test and the Maven line. The voice does not spell the command.

## Film 2. Evidence by default

Use the same headless run as film 1. Show the Allure report contents: steps, screenshots, and logs. Capture the report from its output files. Do not auto-open Allure. Do not claim a report that the run did not write.

## Film 3. The same fluent style on an API

Show one real SHAFT API test: request, check, result. Say that web, mobile, database, CLI, and desktop share one fluent API. Put a real API snippet on screen. Do not stage a mobile or database session in this film. Do not read URLs, headers, or payload keys aloud.

## Film 4. Element recovery

Show `shaft-heal` doing element recovery on a real locator miss in a sample project. The miss happens on camera. The recovery is the product's own result. If the miss cannot be reproduced, do not ship a mocked green heal. Skip the film and say so on issue 7906.

## Film 5. IntelliJ, three stages

Show the shipped three-stage tool window from pull request 5977: Assistant available under every stage, recorder on the default Automation canvas. Capture the IDE. No face in frame. No mocked panels.

## Film 6. ChaosEngine the day after install

Show `doctor` and what a healthy result looks like: core, adapters, local tools, hooks, and detected agent plugins. Show that running the same install line again is how the project stays current, which is the official self-heal path in the installer notes (issue 5811). Label a staged healthy receipt as the success picture. If the machine being recorded is not healthy, do not present its live report as a healthy one.

## Out of scope

Arabic narration is a different slate. A public upload needs its own yes. Live BrowserStack, LambdaTest, or other paid-cloud sessions stay out. Training a voice model stays out.
