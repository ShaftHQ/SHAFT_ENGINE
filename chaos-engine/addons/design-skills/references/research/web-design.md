# Web design: 20 references

Craft card: [../craft/web-design.md](../craft/web-design.md). Each line: link, why it is great,
transferable techniques. Ideas are re-expressed; no media is copied.

1. [Awwwards Sites of the Day](https://www.awwwards.com/websites/sites_of_the_day/): daily juried benchmark of craft. Techniques: read the jury split of design/usability/creativity/content; study scroll pacing.
2. [Linear](https://linear.app/): dense product UI sold through calm restraint. Techniques: near-monochrome UI with one accent; product screenshots as the hero.
3. [Stripe](https://stripe.com/): decade-long reference for developer marketing pages. Techniques: code next to outcome; animated gradients kept behind content.
4. [Vercel](https://vercel.com/): developer-tool site with strict grid and type. Techniques: Geist type system; black/white with data-driven visuals.
5. [Apple](https://www.apple.com/): scroll-driven product storytelling. Techniques: one claim per viewport; image sequences scrubbed by scroll.
6. [Refactoring UI](https://www.refactoringui.com/): practical visual-hierarchy rules for developers. Techniques: limit sizes and weights; de-emphasise instead of emphasise.
7. [Laws of UX](https://lawsofux.com/): psychology principles mapped to UI. Techniques: Hick, Fitts, Jakob laws as review questions.
8. [Nielsen Norman Group](https://www.nngroup.com/articles/): research-backed usability findings. Techniques: F- and layer-cake scanning; 10 heuristics audit.
9. [Web Content Accessibility Guidelines 2.2](https://www.w3.org/TR/WCAG22/): normative accessibility targets. Techniques: 4.5:1 text contrast; 24px target size; reduced motion.
10. [Utopia fluid type](https://utopia.fyi/): fluid type and space scales. Techniques: clamp()-based modular scale between two viewports.
11. [Every Layout](https://every-layout.dev/): intrinsic CSS layout primitives. Techniques: stack, cluster, sidebar; measure in ch.
12. [Butterick's Practical Typography](https://practicaltypography.com/): typography rules for screens. Techniques: 45-90 char line; 120-145% line spacing.
13. [Smashing Magazine](https://www.smashingmagazine.com/): long-form front-end design craft. Techniques: case studies with before/after.
14. [CSS-Tricks](https://css-tricks.com/): reference for CSS technique. Techniques: scroll-driven animation and container queries.
15. [web.dev](https://web.dev/): performance and UX metrics. Techniques: Core Web Vitals: LCP <2.5 s, INP <200 ms, CLS <0.1.
16. [Material Design 3](https://m3.material.io/): documented system of tokens and motion. Techniques: type scale tokens; emphasized easing curves.
17. [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/): platform design guidance. Techniques: clarity, deference, depth; 44pt targets.
18. [Godly](https://godly.website/): curated gallery of motion-rich sites. Techniques: study hero interactions frame by frame.
19. [One Page Love](https://onepagelove.com/): curated single-page sites. Techniques: one scroll, one story.
20. [Lapa Ninja](https://www.lapa.ninja/): landing page gallery. Techniques: compare hero/CTA patterns per category.
