# Graphical overlays: 20 references

Craft card: [../craft/graphical-overlays.md](../craft/graphical-overlays.md). Each line: link, why it is great,
transferable techniques. Ideas are re-expressed; no media is copied.

1. [BBC GEL](https://www.bbc.co.uk/gel): BBC's global experience language. Techniques: subtitle and caption rules.
2. [BBC subtitle guidelines](https://www.bbc.co.uk/accessibility/forproducts/guides/subtitles/): subtitling standard. Techniques: 37 chars/line; 160-180 wpm.
3. [Netflix Timed Text Style Guide](https://partnerhelp.netflixstudios.com/hc/en-us/articles/217350977): caption timing rules. Techniques: 42 chars/line; 5/6 s min-max.
4. [W3C WebVTT](https://www.w3.org/TR/webvtt1/): web caption format. Techniques: cue positioning.
5. [WCAG captions (1.2.2)](https://www.w3.org/WAI/WCAG22/Understanding/captions-prerecorded): caption requirement. Techniques: sync and completeness.
6. [Datawrapper Academy](https://academy.datawrapper.de/): data-viz craft. Techniques: label directly; one message per chart.
7. [Flourish](https://flourish.studio/): animated data stories. Techniques: bar-chart races, scrolly.
8. [The Pudding](https://pudding.cool/): visual essays. Techniques: annotation layers.
9. [Reuters Graphics](https://www.reuters.com/graphics/): newsroom data graphics. Techniques: calm palettes, sharp annotation.
10. [Information is Beautiful](https://informationisbeautiful.net/): designed data graphics. Techniques: clarity through colour coding.
11. [Edward Tufte](https://www.edwardtufte.com/): data-ink and small multiples. Techniques: maximise data-ink ratio.
12. [Storytelling with Data](https://www.storytellingwithdata.com/): chart decluttering. Techniques: grey everything, highlight one.
13. [Envato Elements (anti-reference: templated lower thirds)](https://elements.envato.com/): template overlays to read critically. Techniques: spot templated lower thirds.
14. [NewBlue Titler](https://newbluefx.com/): broadcast title tools. Techniques: live lower thirds.
15. [Singular.live](https://www.singular.live/): web-based broadcast graphics. Techniques: HTML overlays on live video.
16. [CasparCG](https://casparcg.com/): open broadcast graphics server. Techniques: HTML templates in play-out.
17. [OBS Studio](https://obsproject.com/): open streaming overlays. Techniques: browser-source overlays.
18. [Screen Studio](https://screen.studio/): polished screen recordings. Techniques: auto-zoom on cursor.
19. [Arcade](https://www.arcade.software/): interactive product demos. Techniques: hotspot callouts.
20. [Visual Capitalist](https://www.visualcapitalist.com/): dense infographics. Techniques: layered annotation.
