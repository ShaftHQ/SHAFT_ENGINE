# W12 Social proof

## Use when

Proof (quotes, logos, metrics, case studies) goes on a web page, deck,
still or video. Gallery examples are for pattern study only: reference is
not a template ([W01](anti-generic-lint.md)).

## Rules

1. **Proof at decision points:** signup, plans and checkout, not only the
   home page; logos beside the plan cards, reviews beside signup.
2. **Credibility ladder:** face + name + role + company + logo + metric
   beats a quote alone; drop low-detail carousels. Bold the strongest
   sentence as the testimonial headline.
3. **Wall of impact:** metric-led micro case studies, each linking to the
   full story; group metrics by benefit.
4. **Wall of love** over about 9 quotes is filterable by audience or role.
5. **Menu proof:** one customer story slot in a mega menu.
6. **Authority vs impact:** size metrics (countries, learners, years) and
   outcome metrics (hours saved, pass rate) do different jobs; label which.
7. **Certifications and awards** site-wide in the footer.
8. **Video:** testimonial mashup of 3-6 one-line reactions, key phrase on
   screen per speaker, music bed; remote format = question title card,
   answer on camera, key point as text; first-reaction clips split
   stimulus | face.
9. **Long video:** case-study arc challenge → solution → measurable result,
   screen recordings as b-roll only; a person-portrait variant mentions
   the product once.
10. **Slides and stills:** logo wall, impact-metric grid, one-quote-one-face;
    milestone posts = one number, one line, brand frame; proof screenshots
    unedited in one template, one per image, personal data blurred;
    carousel case study = one beat per slide (problem, fix, metric, quote).
11. **Consent and truth:** real quotes only, with permission; never invent
    a metric.

## Verify

- [ ] Each quote has name, role and permission on file; metrics have a source.
- [ ] Proof appears next to the plans and the signup form.
- [ ] Personal data blurred in screenshots.
