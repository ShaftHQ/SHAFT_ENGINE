# W13 Navigation and pricing layout

## Use when

A site's navigation or its plans page is designed. Our cards and content
never state amounts; the page owner supplies them.

## Rules

1. **Pick the nav by IA depth:** static or sticky, dropdown or flyout,
   mega menu, sidebar, search bar, announcement bar, full-screen,
   breadcrumbs, progress bar, tabs. An announcement bar carries one
   time-bound message.
2. **Plans page parts:** tier cards, monthly or annual switch, a short
   per-tier feature list and a full comparison table, feature
   checkmarks, an optional usage calculator, and a custom or enterprise
   option with contact.
3. **Order:** cards first, comparison table below; one highlighted tier.
4. **Proof beside plans** ([W12](social-proof-patterns.md)).

## Verify

- [ ] The nav type is named and matches the depth of the site map.
- [ ] One highlighted tier; the comparison table sits below the cards.
- [ ] No amounts typed into templates, skills or tests.
