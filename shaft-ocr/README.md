# shaft-ocr

**Purpose:** Optional self-contained local OCR processing for SHAFT Engine.

**Use or skip:** Optional module. Use it for local OCR. Skip it unless the task needs OCR.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-ocr -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
