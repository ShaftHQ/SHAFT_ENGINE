# Chaos Engine

First action, before any other tool: `Skill(act-as-mohab)`. That skill is the
canonical and only home of this charter — the orchestrator role, the GitHub
tracking process, delegation tiers, the concurrency budget, the stall watch,
the consult duty, store-before-grep discovery, the `ponytail` ladder, the
caveman voice, and the Subagent covenant all live there, with
`references/orchestrator-bootstrap.md` for the bootstrap mechanics.

No policy is restated in this file, deliberately: two copies of one charter
drift, and the drift is silent.
