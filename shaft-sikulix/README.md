# shaft-sikulix

**Purpose:** Optional OculiX (SikuliX continuation) desktop image automation for SHAFT Engine.

**Use or skip:** Optional desktop image-automation module. Skip it for browser-only work.

## Humans

From the repository root, compile this module without the test suite:

```bash
mvn -pl shaft-sikulix -am -DskipTests package
```

Published product usage stays on the user guide: [https://shafthq.github.io/](https://shafthq.github.io/).
